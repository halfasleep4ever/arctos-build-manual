# Arctos closed-loop build manual (unofficial)

A step-by-step, fan-made build guide for the closed-loop [Arctos](https://arctosrobotics.com/) 6-axis robot arm:
wiring at every step, known problems with fixes, and Simple / Normal / Detailed text levels.

- **Open it:** https://halfasleep4ever.github.io/arctos-build-manual/
- `index.html`: the interactive step-by-step manual. `guide.html`: the reference guide (parts, printing, wiring, MKS setup, troubleshooting).
